# Aulden event questionnaire

Six AI questions and two optional quantum-security questions. Instrument version 1.2.

- Questionnaire: https://bityana.github.io/Bityana-Yishak/aulden-survey/
- Reviewer notes: https://bityana.github.io/Bityana-Yishak/aulden-survey/review/
- Blank paper form: [PDF](forms/Aulden_AI_and_Quantum_Paper_Questionnaire.pdf)

This directory is a static GitHub Pages frontend. It sends answers over HTTPS to a separate private response-storage service. It does not contain responses, owner credentials, or a public results endpoint. The public frontend requires that service to be online with collection enabled.

Question text and option codes are in instrument.json. This is an original exploratory business-opinion questionnaire, not a validated security or quantum-readiness assessment.
